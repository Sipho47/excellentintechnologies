## Timeline

beatPosition integrates BPM/60 over DSP-time tempo segments. Each bar is four beats. A placement at bar N begins on beat (N-1)*4. At a constant BPM, its DSP offset is (N-1)*4*60/BPM; its aligned WAV frame is round(offset*44100).

At 104 BPM:
- Bar 13: musical beat 48; 27.692307692 seconds after transport start; frame 1,221,231.
- Bar 17: musical beat 64; 36.923076923 seconds after start; frame 1,628,308.
- Four-bar hooks occupy [13,17) and [17,21); the endpoint bar is exclusive.

PlayScheduled schedules the native sources within a 200 ms lookahead. Tempo changes apply at the original beat scheduler's next unscheduled boundary; active vocals use a native scheduled end/start handoff with the matching source-sample offset. No beat pattern is expanded or replaced.

## Configuration and limits

No API keys, backend, paid/cloud service or network request were added. The default MockAiVocalProvider needs no setup and produces a synthetic vowel melody, not intelligible sung lyrics. A real IAiVocalProvider remains future work; service secrets must stay in a backend/proxy. Provider labeling is dynamic so swapping providers does not require rewriting the UI. Providers must return 44.1 kHz interleaved stereo PCM and generation settings.

Open Assets/Scenes/BacardiBeatMaker.unity, enter Play mode and scroll to AI VOCAL GENERATOR. Generate; select HOOK 1: 13 and ADD TO SONG; select HOOK 2: 17 and ADD TO SONG. EXPORT VOCAL STEM exports all committed placements. No automatic scene modifications or manual component attachment is required.

Vocal placements are session-local. Tempo conversion is resampling and changes pitch; pitch-preserving stretching is not implemented. Stem exports use the current constant project BPM. The existing one-bar Full Mix/instrument/MIDI exports remain unchanged and do not become a full-song vocal master exporter.
